### BE_AUTH_004 로그인 · 토큰 갱신

| 항목 | 내용 |

## 5 공통 기술 컨텍스트

### 백엔드

- 스택: Spring Boot · Security · JPA · Redis/Redisson · MariaDB · S3 · Java Mail · PortOne(Iamport) · STOMP/WebSocket
- 역할: `ROLE_CUSTOMER`, `ROLE_COMPANY`
- 토큰: `ATOKEN`(1시간), `RTOKEN`(5일), Redis `refreshToken:{userId}`, `WTOKEN`(대기열 TTL 10분)

### 프론트엔드

- 스택: Vue 3 · Vue Router 4 · Pinia · Axios · vue-toastification · Daum Postcode · PortOne(Iamport) · SockJS/STOMP
- 인증: HttpOnly 쿠키 및 `withCredentials`
- 역할: `ROLE_CUSTOMER`, `ROLE_COMPANY`
- 상태 저장: Pinia 및 `sessionStorage` persist
